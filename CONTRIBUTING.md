# Como contribuir

1. Atualize sua branch `main` antes de começar.
2. Crie uma branch com prefixo `feat/`, `fix/` ou `docs/`.
3. Faça commits pequenos, com mensagens que descrevam a mudança.
4. Não adicione `data/raw/`, `data/processed/`, modelos, índices, `.venv` ou `node_modules` ao Git.
5. Execute os testes relevantes e descreva no Pull Request como reproduzi-los.
6. Abra um Pull Request para `main`; solicite revisão de pelo menos um integrante.
7. Não sobrescreva resultados experimentais sem guardar as configurações e condições da execução.

## Checklist de Pull Request

- [ ] A mudança tem escopo e descrição claros.
- [ ] Os caminhos de dados e segredos não foram adicionados.
- [ ] As dependências foram atualizadas no arquivo correto.
- [ ] Testes ou comandos de verificação foram executados.
- [ ] A documentação foi atualizada quando necessário.
